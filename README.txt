PROJETO NEXT.JS + SUPABASE AUTH COMPLETO
=======================================

Tudo o que você precisa fazer para rodar este projeto:

1. Extraia o conteúdo deste arquivo .zip em uma pasta vazia.
2. Abra o terminal / prompt de comando exatamente dentro dessa pasta.
3. Instale as dependências executando:
   npm install

4. Abra o arquivo '.env.local' e configure com as chaves do seu projeto do Supabase:
   - NEXT_PUBLIC_SUPABASE_URL
   - NEXT_PUBLIC_SUPABASE_ANON_KEY

5. Inicie o servidor de desenvolvimento rodando:
   npm run dev

6. Abra o navegador e acesse:
   http://localhost:3000/login
